# Windsage — Code Overview (README_GIT)

This document explains what the code in `src/` does, the runtime flow, and the external interfaces used.

## Project overview

- Purpose: Track repository artifacts and commits, persist them to PostgreSQL, and notify a Windstorm webhook when a repository's head changes on the default branch.
- Primary files:
  - `src/env.py` — environment configuration (DB and webhook URL)
  - `src/main.py` — application logic, SQLAlchemy ORM models, DB operations, webhook notifier

## Environment variables (and defaults)

- `SQLHOST` — host:port for Postgres (default: `localhost:5432`)
- `DBUSER` — database user (default: `postgres`)
- `DBPASS` — database password (default: `mysecretpassword`)
- `DBTABLE` — target database name (default: `sysml2`)
- `WINDSTORMHOST` — URL for Windstorm webhook (default: `http://windstorm-webhook-eventsource-svc.argo-events:12000/windstorm`)

All of these are defined in `src/env.py` and imported by `src/main.py`.

## Database schema (ORM models)

Two tables are used (via SQLAlchemy ORM models):

- `artifacts` (model `Artifacts`):
  - `id`: primary key (auto)
  - `full_name`: repository full name (`owner/repo`)
  - `commit_url`: URL to the repository/commits
  - `default_branch`: repository default branch name

- `artifact_commits` (model `Artifacts_Commits`):
  - `id`: primary key (auto)
  - `artifacts_id`: FK -> `artifacts.id`
  - `ref`: branch/ref name (e.g. `main`)
  - `commit`: commit SHA
  - `date`: when recorded

## High-level runtime flow

1. The script's `main(ref, commit, full_name, commit_url, default_branch)` is invoked (via `fire` CLI when run directly).
2. Normalize `ref` (strip `refs/heads/` if present).
3. If `ref` is not equal to `default_branch`, skip processing.
4. Connect to the Postgres database (`connect()` builds SQLAlchemy URL and engine).
5. Lookup `Artifacts` by `full_name`:
   - If not found, insert a new `Artifacts` row and get its `id`.
   - If found and `default_branch` differs, update the stored default branch.
6. Check if an `Artifacts_Commits` entry exists for the (`ref`, `commit`) pair.
   - If not, insert a new `Artifacts_Commits` row with current timestamp.
7. Close DB session/engine.
8. POST a JSON notification to the `WINDSTORMHOST` webhook with the `artifact_id`.

## Interfaces

- Internal modules:
  - `src/env.py` — configuration constants imported by `src/main.py`.
- External systems:
  - PostgreSQL: read/write via SQLAlchemy engine/ORM.
  - Windstorm webhook: HTTP POST to `WINDSTORMHOST` with JSON payload `{ source: 'sage', payload: { artifact_id: <id> } }`.
- CLI: the code uses `fire` (Google Fire) to expose `main()` as a CLI function when run as `python -m src.main`.

## Example usage

Run `main` directly for manual testing (from repository root):

```bash
python -m src.main "refs/heads/main" "<commit-sha>" "owner/repo" "https://example/commit/url" "main"
```

## Notes & troubleshooting

- Ensure environment variables in `src/env.py` are set for production (do not use defaults with sensitive data).
- The DB connection string is constructed as `postgresql://<user>:<pass>@<host>/<db>`; make sure `psycopg2` (or the configured DB driver) is installed and available to SQLAlchemy.
- If you plan to run in a container/orchestrator with an internal Windstorm service, update `WINDSTORMHOST` appropriately.
